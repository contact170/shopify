À coller dans Shopify : Paramètres > Notifications > Notifications client > Confirmation de commande.
Variables ajoutées
dw_point_relais : true si le client a choisi la livraison en point relais Chronopost.
dw_delai        : délai de livraison annoncé selon le mode de livraison.

pour afficher le bon guide d'installation.
dw_nb_articles  : nombre total d'articles de la commande.
Le style est entièrement défini dans ce fichier (classes « dw- ») : la feuille de style
Shopify par défaut (/assets/notifications/styles.css) n'est plus chargée.
